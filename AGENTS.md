# WikiContext

Read README.md and docs/data-model.md before changes. Use default users and shared-workspace access. Read through authenticated schema/SQL; write through PocketBase REST. Preserve immutable sources and revisions, atomic publication, revision conflicts, citations, audit history, and protected files. Never commit real wiki data, tokens, pb_data, or generated vaults. Follow README validation commands.
